# 🌸 SHIV SHAKTI GENERAL STORE - Frontend

Welcome to the beautiful frontend of **Shiv Shakti General Store**, a premium boutique shopping experience for cosmetics, jewellery, and skincare.

## ✨ Features

- **🛍️ Premium Shopping**: Browse curated collections of beauty products.
- **🔐 Google Sign-In**: Quick and secure login using your Google account.
- **✉️ OTP Verification**: Secure email verification for new signups.
- **💳 Dual Payments**: Support for both **Cash on Delivery (COD)** and **Online Payments (Razorpay)**.
- **📦 Order Tracking**: View your purchase history and payment status in real-time.
- **🎨 Modern Design**: Vibrant, aesthetic, and fully responsive UI.

## 🛠️ Built With

- **React + Vite** (Fast & Modern)
- **Tailwind CSS** (Beautiful Styling)
- **Lucide React** (High-quality Icons)
- **Axios** (Backend Communication)

## 🚀 Quick Start

1. **Clone the project**
   ```bash
   git clone https://github.com/mahesh4596/ssgs-frontend.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Setup Environment Variables**
   Create a `.env` file in the `frontend` root:
   ```env
   VITE_API_URL=http://localhost:5000/api
   ```

4. **Run Development Server**
   ```bash
   npm run dev
   ```

## 🌐 Deployment (Vercel)

1. Connect your GitHub repository to [Vercel](https://vercel.com).
2. Set the **Root Directory** to `frontend`.
3. Add the Environment Variable `VITE_API_URL` pointing to your live backend URL.
4. Click **Deploy**!
